# Analysis and prediction of heart disease

This project consists of an analysis of a dataset containing data from patients. The analysis focuses on preparing and selecting the right attributes to build a machine learning model to predict heart disease.

The files below show the same analysis, but in different languages.

 - Analysis_and_prediction_of_heart_disease.ipynb: English version.
 - Análise_e_predição_de_doença_cardiaca.ipynb: Portuguese version.
